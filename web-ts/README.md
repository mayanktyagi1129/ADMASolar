# ADMA Solar — TypeScript site

TypeScript conversion of the Hostinger PHP site (`admasolar.com/new/`).

This is an independent Vite + TypeScript app. It is **not** deployed from `main` or `hostinger-live`.

Source lives on the `typescript` branch of `mayanktyagi1129/ADMASolar` under `web-ts/`.
`main` and `hostinger-live` are unchanged and still serve the original GitHub Pages site.

```powershell
npm install
npm run dev
npm run build
```
